# Literatura i poveznice

Popis izvora za poglavlje *Literatura* završne dokumentacije. Preuzete PDF datoteke (datasheetovi, članci)
spremaju se u `OSTALO/literatura/`.

## Platforme i protokoli

- ThingsBoard CE – dokumentacija: https://thingsboard.io/docs/
- ThingsBoard – Gateway MQTT API (most edge → ThingsBoard): https://thingsboard.io/docs/reference/gateway-mqtt-api/
- ThingsBoard – REST API (mobilna aplikacija): https://thingsboard.io/docs/reference/rest-api/
- MQTT 3.1.1 specifikacija (OASIS): https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html
- Eclipse Mosquitto: https://mosquitto.org/documentation/
- JSON Schema (komunikacijski ugovor): https://json-schema.org/
- Docker: https://docs.docker.com/

## Računalni vid i OCR

- OpenCV – dokumentacija: https://docs.opencv.org/
- Tesseract OCR: https://tesseract-ocr.github.io/tessdoc/

## Mikrokontroleri i senzori

- ESP32 – datasheet (Espressif): https://www.espressif.com/sites/default/files/documentation/esp32_datasheet_en.pdf
- Arduino core za ESP32: https://docs.espressif.com/projects/arduino-esp32/
- PlatformIO: https://docs.platformio.org/
- PubSubClient (MQTT klijent za Arduino): https://github.com/knolleary/pubsubclient
- ArduinoJson: https://arduinojson.org/
- HC-SR04 ultrazvučni senzor – datasheet: https://cdn.sparkfun.com/datasheets/Sensors/Proximity/HCSR04.pdf

## Alati za maketu i dokumentaciju

- OpenSCAD (3D dijelovi): https://openscad.org/documentation.html
- WireViz (dijagrami ožičenja): https://github.com/wireviz/WireViz
- Pandoc (sastavljanje dokumentacije): https://pandoc.org/
- Mermaid (dijagrami u Markdownu): https://mermaid.js.org/
