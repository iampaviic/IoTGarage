INSTALL - instalacija i pokretanje
==================================

Sve naredbe se pokrecu iz mape SOFTWARE (osim ako pise drugacije).
Detaljnije upute: PROJEKT/dokumentacija/03-korisnicke-upute.md i
04-tehnicka-dokumentacija.md te README.md u svakoj podmapi.


1. Preduvjeti
-------------
- Python >= 3.8, git
- Tesseract OCR i Mosquitto MQTT broker
    Linux:   sudo apt install tesseract-ocr mosquitto
    Windows: instalacijski programi s tesseract-ocr.github.io i mosquitto.org
- Docker (za ThingsBoard, opcionalno za edge racunalo)
- PlatformIO (VS Code ekstenzija ili: pip install platformio) - firmware
- opcionalno: OpenSCAD (3D dijelovi), WireViz + Graphviz (sheme ozicenja)


2. Python okruzenje i testovi (laptop)
--------------------------------------
    python -m venv .venv
    source .venv/bin/activate          (Windows: .venv\Scripts\activate)
    pip install -r requirements-dev.txt
    pytest                             (svi testovi, ~1 min)


3. Cijeli sustav bez hardvera (simulacija)
------------------------------------------
    python integracija/simulacija.py --broker
    python integracija/simulacija.py --broker --interactive
Pokrece Mosquitto, simulatore senzora i rampi, ALPR sa sintetskom kamerom,
kontrolu pristupa i bazu, te odigra demo scenarij.


4. ThingsBoard (laptop ili server s >= 4 GB RAM)
------------------------------------------------
    cd thingsboard
    docker compose up -d                (prvo pokretanje traje par minuta)
    python provision/provision.py       (uredjaji, alarmi, dashboardi)
Web: http://localhost:8080, prijava tenant@thingsboard.org / tenant
(promijeniti lozinku!). Port 1884 = MQTT za most s edge racunala.
Simulacija s ThingsBoardom: python integracija/simulacija.py --broker --tb


5. Firmware za ESP32 (cvor senzora i cvor rampi)
------------------------------------------------
Za svaki cvor (senzori/firmware i rampe/firmware):
    1. kopirati include/secrets.example.h u include/secrets.h i upisati:
         WIFI_SSID, WIFI_PASSWORD     - mreza makete
         MQTT_HOST, MQTT_PORT         - IP edge racunala, 1883
         MQTT_USER, MQTT_PASSWORD     - prazno = anonimno
         NTP_SERVER                   - izvor vremena
       (secrets.h se ne komita)
    2. pio run -d senzori/firmware -t upload
    3. pio device monitor -d senzori/firmware   (115200 baud)
Pinovi i pragovi: include/config.h; shema spajanja:
PROJEKT/maketa/shema-spajanja.md.


6. Edge racunalo (Raspberry Pi ili Jetson Nano)
-----------------------------------------------
a) Docker (preporuka):
    cd edge/deploy
    docker compose -f docker-compose.edge.yml -f docker-compose.camera.yml up -d --build
   (bez kamere izostaviti docker-compose.camera.yml - sintetska kamera)
b) Nativno (Raspberry Pi OS / Ubuntu, Python >= 3.8):
    bash edge/deploy/install_native.sh
   Skripta instalira Mosquitto i Tesseract, napravi .venv u ovoj mapi,
   kopira edge/edge.example.yaml u edge/edge.yaml; zatim po uputama koje
   ispise ukljuciti systemd servise iz edge/deploy/.

Konfiguracija: edge/edge.yaml (kamera, pragovi pouzdanosti, naplata,
privatnost; objasnjenja su u edge.example.yaml). Varijable okruzenja
(nadjacavaju edge.yaml; za Docker se postavljaju u docker-compose.edge.yml,
za nativnu instalaciju u .service datotekama):
    MQTT_HOST, MQTT_PORT, MQTT_USERNAME, MQTT_PASSWORD, MQTT_KEEPALIVE
    GARAGE_DB          putanja SQLite baze sesija
    GARAGE_SPOTS       broj parkirnih mjesta
    PRICING_PROFILE    real ili demo (demo: 1 minuta = 1 sat)
    ALPR_SOURCE        camera, sim (sintetske slike) ili images (mapa s
                       fotografijama, images_dir u edge.yaml)
    TB_HOST, TB_MQTT_PORT, TB_GATEWAY_TOKEN   ThingsBoard za most
    TB_BUFFER          datoteka medjuspremnika kad ThingsBoard nije dostupan
    TB_URL, TB_USER, TB_PASSWORD              za provision.py i alate


7. Maketa
---------
    python maketa/alati/tlocrt.py --scale 24 --spots 6 --print-tiles
    python maketa/alati/kamera_kalkulator.py
    python maketa/elektronika/generiraj_sheme.py   (treba wireviz)
STL dijelovi za 3D ispis: maketa/3d/stl/. Popis komponenti i nacrt:
PROJEKT/maketa/.
