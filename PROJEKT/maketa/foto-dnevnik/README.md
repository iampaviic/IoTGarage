# Foto-dnevnik izrade

Isporučivi rezultat su i **fotografije faza izrade**. Pravila:

- naziv: `YYYY-MM-DD_faza-N_opis.jpg` (npr. `2026-11-02_faza-3_most-senzora.jpg`), faze iz [nacrt-makete.md](../nacrt-makete.md) §5
- svaka faza: 1 pregledna + 1–2 detalja (spojevi, montaža)
- prije zatvaranja kanala: fotografija ožičenja s vidljivim oznakama kabela
- bez ljudi i stvarnih vozila/registracija u kadru
- velike datoteke smanjiti na ~1600 px širine prije komitanja (ili čuvati u dijeljenom disku i ovdje staviti poveznicu)
